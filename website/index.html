An editor that works the way Emacs works.

The same buffers, windows, keys and commands, with a Rust core and its commands in TypeScript. This is E8 itself, compiled to WebAssembly and running in your browser: click in it and type.

C-x C-f opens a file M-x runs a command C-x d lists a directory C-x 3 splits the window M-s l searches the lines M-: evaluates TypeScript C-c t chooses a theme

On a phone, the keys under the editor give you Esc, Ctrl, Alt, Tab and the arrows, and the last of them brings up the keyboard.

Install

With Homebrew, on Apple silicon Macs and on Linux:

brew install e8-editor/tap/e8

That gives e8, the editor in a terminal, and on a Mac E8.app, the editor in a window. To open the app from Launchpad and Spotlight:

ln -sf "$(brew --prefix)/opt/e8/E8.app" /Applications/E8.app

There is also a Nix flake. Your configuration goes in ~/.config/e8/init.ts.

What it does

Files and Dired

Visiting, saving, backups and auto-saving, Dired to manage directories, projects to find your way around them.

Windows and frames

Splitting, resizing and switching, several frames, and the keys your fingers already know.

Search and replace

Isearch and query-replace with Emacs's own regexps, completion in the minibuffer, compiling and grepping.

Org mode

Headings, folding, tables, the agenda and capture, following Org's behaviour.

Modes and faces

Tree-sitter modes, faces and themes, images and bidirectional text, a shell.

An agent

An agent that calls E8's commands as tools, asking before it writes files or runs code. E8 is also an MCP server.

How it is made

What Emacs writes in C, E8 writes in Rust; what Emacs writes in Lisp, E8 writes in TypeScript, which is also how you configure and extend it. The app runs its TypeScript on V8; this page runs it on QuickJS, with the editor on a Web Worker and your files kept in this browser's storage.

The editor above starts with a configuration as yours would be: ~/.config/e8/init.ts, which sets up the ports of Vertico, Orderless, Marginalia, Consult, Vundo, Casual and persistent-scratch, each a repository of its own, and twenty themes in one. Open it with C-x C-f, change it and save it: from then on it is yours. Without it, E8 starts as it ships.

E8 is built by one person for daily use, and is open so that it is not hidden. It is free software, under the GPL.
