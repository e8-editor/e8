#+TITLE: E8 in your browser

* Welcome
E8 is an editor that works the way Emacs works, written in Rust, with
its commands in TypeScript. This is the real editor, compiled to
WebAssembly, running in this page.

Click here to focus it, then try some keys. =TAB= on a heading folds
it, =S-TAB= folds them all.

* Things to try
- =C-x C-f= visits a file and =C-x C-s= saves it: your files are kept
  in this browser, in =~=, and are there when you come back
- =C-x d= opens Dired on a directory; try =~/notes/= and =~/scripts/=
- =C-x b= switches buffers: there is a Python one and =*scratch*=
- =M-x= runs any command by name, with completion
- =C-s= searches as you type, =M-%= replaces
- =C-x 2= and =C-x 3= split the window, =C-x o= moves between them
- =C-x u= or =C-/= undoes
- =M-:= evaluates TypeScript: try =[1, 2, 3].map(n => n * n)=
- =M-x load-file= runs a script: =~/scripts/hello.ts= defines =M-x hello=
- =~/.config/e8/init.ts= runs each time E8 starts. On the website it
  sets up vertico, orderless, marginalia and consult: try =M-s l= to
  search the lines, =M-g o= for the headings, =C-z= for the undo tree

* What this page cannot do yet
Files live only in this browser: they are not your computer's. There
is no shell or compiling, no agent, and the system clipboard is not
shared. Some keys belong to the browser: =C-w=, =C-n= and =C-t= may
close or open tabs instead.
